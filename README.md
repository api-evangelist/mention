# Mention (mention)
Mention is a media monitoring and social listening platform that monitors over one billion sources in real-time across 42 languages. Its JSON-based RESTful API gives developers programmatic access to alerts, mentions, streaming data, and account management features.

## APIs

### Mention API
The Mention API is a JSON-based RESTful API that gives developers access to Mention's media monitoring features. It supports managing alerts, listing and streaming mentions, and integrating monitoring data into custom workflows.

**Human URL:** [https://api.mention.com/](https://api.mention.com/)
